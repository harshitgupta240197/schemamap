Schema Map is a free, open-source tool for SQL Server. It draws a map of every table, relationship and dependency, including the relationships nobody ever declared.

Join the waitlist

Reads metadata only. Never row data.

The map file cannot send anything anywhere. Schema Map connects with a read-only login and reads only the system catalog: table, column, key and dependency definitions. It does not read the rows in your tables. The map is one file that opens offline in your browser, and its security policy blocks every network request.

From one table to the whole estate

Who it is for

  • DBAs who inherited a database with no documentation and need to know what breaks if a table changes.
  • BI developers who need to find the right tables and the join paths between them.
  • Data engineers who are about to migrate, refactor or document a SQL Server estate.

Pulse: performance insights, coming later

The map shows how a database is built. Pulse will show how it behaves, using the same metadata-only approach. It is not ready yet. Joining the waitlist is the way to hear about it.
