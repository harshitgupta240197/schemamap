  • Needs fixing

    Can see object definitions (VIEW DEFINITION)

    schemamap_reader can sign in but can’t see table, view or procedure definitions in AdventureWorks2022. A map made now would be empty.

    How to fix: ask a DBA to run this script once in each database you want to map. It grants metadata visibility only: no SELECT, so the login still can’t read a single row.

    Permission script · T-SQL 
    -- Schema Map permission script for [schemamap_reader]
-- Grants metadata visibility only. No SELECT on your tables, so no row data.
USE [AdventureWorks2022];
IF USER_ID(N'schemamap_reader') IS NULL
    CREATE USER [schemamap_reader] FOR LOGIN [schemamap_reader];
GRANT VIEW DEFINITION TO [schemamap_reader];
GRANT SELECT ON sys.sql_expression_dependencies TO [schemamap_reader];

-- Optional: row counts and table sizes
GRANT VIEW DATABASE STATE TO [schemamap_reader];
