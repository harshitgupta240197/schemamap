how it works

Three steps, no setup on the server

1. Connect

Use a read-only login

Schema Map reads the system catalog only. It never needs SELECT on your tables and never writes anything.

2. Map

Get one offline file

The map is a single HTML file. Open it in any browser, search for a table, and follow its keys in seconds.

3. Understand

See what breaks

Pick any table to see its columns, keys, indexes, and every view or procedure that depends on it.

from one table to the whole estate

Every detail, one click away

Focus on a table and its neighbours, then open the side panel for columns, types, keys and indexes. Large databases open as a calm overview, one box per schema, so 2,000 tables stay readable.

  • Search any table, column or view with /
  • Works fully with the keyboard, in light and dark
  • Share a link straight to a table or a focus view
built for cautious DBAs

Reads metadata only. Never row data.

The map file cannot send anything anywhere. Its security policy blocks every network request, so you can say yes without a security review.
